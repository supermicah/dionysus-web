# dionysus-web

> A test API service based on golang.

## Environment Prepare

> You can use [nvm](https://github.com/nvm-sh/nvm) to manage node version.

- Node.js v16.20.2

## Quick Start

### Install dependencies

```bash
npm install
```

### Start project

```bash
npm start
```

### Build project

```bash
npm run build
```
